# custom/

Loyihaga xos (Uzinkass) qo'shimcha kod va kengaytmalar shu yerda saqlanadi.

Maqsad: Traccar core (`traccar/` submodule) ga **to'g'ridan-to'g'ri tegmasdan**, o'z qo'shimchalaringizni alohida saqlash. Shunda Traccar'ni yangilash (`git submodule update --remote`) oson bo'ladi.

Bu yerga qo'shish mumkin:
- Maxsus protokol dekoderlari (agar core'ga qo'shilsa — patch ko'rinishida)
- REST API ustida ishlaydigan integratsiya skriptlari
- Hisobot / tahlil vositalari
- SMS / Telegram bildirishnoma skriptlari
