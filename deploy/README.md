# deploy/

Serverga joylash (deployment) va sozlash fayllari.

- **`traccar.xml.example`** — Traccar asosiy konfiguratsiya namunasi. Uni `traccar.xml` deb nusxa qilib, parolni to'ldiring. Haqiqiy `traccar.xml` `.gitignore` orqali repoga tushmaydi (maxfiylik).

Kelajakda shu yerga qo'shish mumkin:
- `docker-compose.yml`
- `nginx` konfiguratsiyasi
- DB zaxira (backup) skriptlari
- `systemd` xizmat fayllari
